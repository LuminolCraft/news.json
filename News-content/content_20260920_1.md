### 纯净生存服启用账号绑定的公告与操作指南

2026年暑假以来，纯净生存服（以下简称纯净服）的在线人数持续走高。这固然令人欣喜，但也让管理压力与日俱增。为保持服务器的玩法纯净与最少插件原则，经 **NaT_Jerry** 与 **Narcssu** 等管理员策划与开发，我们正式启用**账号绑定**功能——即将游戏角色与可追溯的邮箱（仅允许需要手机号等验证、难以批量注册的邮箱域名）通过官网账号系统绑定。**未绑定的游戏 ID 将无法进入纯净服**，以此实现高效管理，减少小号熊服等有损玩家利益的行为。

目前官网账号系统已开放，玩家可进行注册，并在服务器**大厅**内完成账号绑定。

> **注**：禁止未绑定玩家进入纯净服的调整计划于 **2026 年寒假前**实施，请各位玩家尽快完成绑定。

#### 操作指南

**第一步：注册与验证**

访问[官网](https://craft.luminolsuki.moe)，点击右上角登录按钮，选择注册。已有账户可直接登录；拥有 GitHub 账户的，也可通过下方的 GitHub 登录，无需注册。

> **注意：GitHub 登录仅允许符合上述邮箱条件的GitHub账户使用。**

设置一个**唯一的**用户名，输入邮箱，设置一个**安全的**密码并确认。

> <img src="https://imagehosting-ez2.pages.dev/avif/Signup-1.avif" alt="img" width="720">

注册完成后系统会提示验证账户。请前往你的电子邮箱，找到标题带有 `[LuminolCraft]` 字样的**邮件**（若找不到，请检查垃圾邮件或其他分类）。点击邮件中的链接完成验证，然后使用注册邮箱和密码登录。

> <img src="https://imagehosting-ez2.pages.dev/avif/88ab4b3ed2b72bfb0da045bfc925dea1.avif" alt="img" width="720">

**第二步：绑定游戏账户**

登录后，网站左上角会显示你的用户名。点击用户名进入账户管理界面，点击左侧 **Minecraft** 按钮，在详情页找到 **“绑定新账户”** 及其下方的游戏名输入框。

> <img src="https://imagehosting-ez2.pages.dev/avif/Verify-1.avif" alt="img" width="720">

输入你的游戏 ID 后点击 **“绑定”** 按钮。网站会显示一个 6 位数验证码，有效期为 600 秒（10 分钟）。请在此期限内**迅速打开游戏进入服务器大厅**，输入 `/v [验证码]` 并执行。看到“绑定成功”提示后，即完成绑定。

> <img src="https://imagehosting-ez2.pages.dev/avif/Verify-2.avif" alt="img" width="720">

**第三步：绑定小号（可选）**

每个账户每周有一个小号绑定名额，不可叠加。操作流程同第二步。

**第四步：解绑游戏账户（可选）**

点击想解绑的游戏账户旁的红色解绑按钮，**认真阅读警告并二次确认后**即可完成。

info、marketing、sales、billing、jobs、careers、press、media、legal、compliance

**站点路由词**

login、register、signup、signin、logout、settings、profile、dashboard、api、static、assets
